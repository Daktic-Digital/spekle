description: Set up the ADR directory, index, and ADR 0001
---

Initialize Architecture Decision Records in this repository using the
conventions from the adr skill (read `skills/adr/SKILL.md` in this plugin).

Check for an existing ADR convention in the repo first (`docs/adr/`,
`doc/architecture/decisions/`, `adr/`, `docs/decisions/`) and adopt it rather
than creating a second location. Otherwise create `docs/adr/` with an index at
`docs/adr/README.md`, then write ADR 0001 titled "Record architecture
decisions" documenting the decision to use ADRs, this format, and their
location.
